The actual dashboard philosophy

Compact, local, information-dense.

No giant glowing widgets or decorative gradients. The app uses a dark surface hierarchy, restrained borders, monospace numbers, compact labels and color only where status matters.

01 · Overview

Node + pool status

Sync state, current job, heartbeat/share activity, connection endpoint and headline mining figures live together.

02 · Miners

Worker cards

Each worker gets hashrate, shares, difficulty, best share, uptime and best-share context.

03 · Blocks

Block history

Recent block candidates and results are presented as dense tables rather than oversized marketing cards.

04 · Settings

Pool controls

Payout address, storage/pruning and difficulty controls use the same compact form treatment.

05 · Diagnostics

Useful detail, collapsed

Node and pool diagnostics stay available without overwhelming the primary Overview screen.

06 · Alerts

Semantic status

Green, amber and red communicate state; the interface does not rely on glow or decoration to explain health.

Deployment

Built from the same UI system.

The public BCH and XEC packages use the same dashboard design language: Overview, Miners, Blocks and Settings, with coin-specific telemetry layered into that structure.

SHA-256

Run your node and solo pool locally, expose Stratum to your ASICs, and keep the operational details in the dashboard.

  • Node synchronization and health
  • Share heartbeat and recent shares
  • Worker cards and best shares
  • Difficulty / VarDiff controls
  • Payout configuration

Scrypt + merged mining

The AIO package extends the same approach to Scrypt pools, including Litecoin + Dogecoin merged mining and Bellscoin.

  • Separate pool telemetry
  • Per-pool worker statistics
  • Difficulty controls
  • Payout settings
  • Block and record alerts
Example endpoints: BCH uses stratum+tcp://<umbrel-ip>:3334; XEC uses stratum+tcp://<umbrel-ip>:3335. Actual AIO ports depend on the pool configuration.

Get started

Install it on Umbrel.

Add the community store, install the pool package, configure your payout and point your miner at the local Stratum endpoint.

1 · Add the app store

Use the Soggy Pools community app store repository in Umbrel.

https://github.com/SoggyHammyDev/soggy-pools-store

2 · Configure and mine

Open the dashboard, configure the pool, wait for node sync, then connect your miner.

Dashboard → Settings → Save → Sync → Mine
