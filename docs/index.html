Under the hood

Self-hosted from node to Stratum.

Your Umbrel runs the services. Soggy Pools provides the dashboard and the glue between your node, pool software and miners.

SHA-256 stack

A typical SHA-256 deployment connects a coin node to a CKPool-derived solo pool backend, then exposes a local Stratum endpoint to your ASICs.

  • Coin node + RPC
  • Pool / Stratum service
  • Local web dashboard
  • Miner and share telemetry
  • Difficulty + payout configuration

Scrypt stack

The AIO build adds Scrypt mining with Litecoin + Dogecoin merged mining, independent DigiByte Scrypt, and Bellscoin via AuxPoW.

  • Separate Scrypt pools
  • Independent worker views
  • Per-pool difficulty controls
  • Payout configuration
  • Discord record alerts

Get started

Install it. Point a miner at it. Start hunting.

Soggy Pools is intended for people who want the pool stack on hardware they control instead of handing their mining telemetry to a hosted service.

1 · Add the Umbrel store

Add the Soggy Pools community app store to your Umbrel, then install the package you want.

https://github.com/SoggyHammyDev/soggy-pools-store

2 · Configure your pool

Open the dashboard, set your payout destination, choose node storage/pruning options where available, and let the node sync.

Dashboard → Settings → Save → Sync → Mine
